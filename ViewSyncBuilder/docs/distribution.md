# ViewSync Builder 開発用プレビュー

このパッケージはmacOS arm64向けのローカル検証用です。

1. ZIPを展開します。
2. `Start ViewSync Builder.command`を開きます。
3. ブラウザでプロジェクトを作成し、写真・CTを読み込みます。
4. 写真だけのメッシュ試作は「座標と用途」→「写真だけの形状試作」、生成物は「テクスチャまで」を選びます。CT整合・物理単位は未検証です。Sparseだけの工程実行にも対応します。
5. CTへ整合する場合は、既知のCT座標を持つ拘束GCPを3点以上（4点以上を推奨）、各2画像以上で登録します。独立評価点は別の役割で登録します。
6. 最終出力後、「結果確認」から成果物ZIPを保存します。

Python、Node.js、COLMAP、学習済みモデルは追加インストールせず同梱分を使用します。
OpenMVS 2.4.0のCPUエンジンを同梱し、Dense→メッシュ→写真テクスチャ→OBJ/GLB出力までアプリ内で実行します。
OpenMVSはAGPL-3.0で、第三者ライブラリに研究用途制限の記載があります。`resources/engines/openmvs-2.4.0/`に対応ソースZIP・LICENSE・COPYRIGHTを同梱しています。商用配布条件を満たした製品版ではありません。[公式ライセンス](https://github.com/cdcseacave/openMVS/blob/v2.4.0/COPYRIGHT.md)。
CTの内部欠損は取り込み時に検出してHU線形補間します。元DICOMと補間位置・由来を保存し、MPRと参照点に補間影響を表示します。基本間隔を特定できないデータ、重複、座標不整合はエラーになります。補間影響のある参照点を使う結果はCT精度を保証しません。
実行時のHTTPは127.0.0.1に限定します。ブラウザタブを閉じても実行中のジョブは続きます。停止は画面の「中断」で行ってください。
