# コードとローカルデータの分離

## 現行配置

```text
UXbrowse/
├── MacAR/                 Pythonコード・browser_ui・tests・docs
└── data/
    ├── MacAR/             ローカル専用・Git管理対象外
    │   ├── 260918splat/    ローカル撮影素材
    │   ├── colmap_image/   RC/COLMAPと元画像
    │   ├── image/
    │   ├── output_*/      参照view・特徴地図・前処理・検証結果・ログ
    │   └── .model_cache/  学習済みモデルと索引
    └── 260911/ 等         既存ビューア共用データ（配置は変更しない）
```

コードは`MacAR/`から従来と同じコマンド・VS Code設定名で実行する。データの既定ルートは`data/MacAR/`、変更する場合は起動前に`VIEWSYNC_MACAR_DATA_DIR`を指定する。各CLIの明示的な入力・出力パスも引き続き使える。旧コードフォルダへの探索フォールバックやsymlinkは作らない。

3DGS・登録実写の両方式、モデル・地図の選択、単位・座標・PnP/QC条件は変えない。CT/MHAとモデル座標JSONは従来の共用`data/260911/`を使う。Google Drive等を指す地図の外部入力パスは移動しないため、その外部データも引き続き必要。

## 既存ローカルデータの配置変更

ライブ・前処理・ベンチマークを停止してから`MacAR/`で実行する。

```sh
.venv/bin/python separate_macar_data.py          # 移動予定だけ表示
.venv/bin/python separate_macar_data.py --apply  # 上書きせず移動
```

対象はMacAR直下のデータ用ディレクトリ（`output`、`output_*`、`image`、`colmap`、`colmap_image`、`260918splat`、キャッシュ）と地図選択JSONだけ。コード・依存環境`.venv`・描画ツール`.tools`は移動しない。移動先に同名項目があれば実行前に停止し、マージ・削除・上書きしない。元データは同一ファイルシステム内でrenameして保持する。

運用に必要なsummary/manifest/state/config/audit/選択JSONだけ、移動対象内を指す絶対パスを新配置へ更新する。元JSONと移動記録を移動先の`layout-migrations/`に保存する。幾何・descriptor・XYZ・画像・測定値・JSONLログは変更しない。JSONの更新はパスだけであり、mtimeを保持して既存の幾何監査を不要に無効化しない。既定地図の読込・監査は移動後に別途検証する。過去結果のsnapshotスクリプトやログ内の旧絶対パスは履歴として保持し、再実行時は新しい配置の入力を指定する。

## GitHubへ載せる範囲

`data/MacAR/`全体と、コード側に誤生成されたデータ・キャッシュを`.gitignore`で除外する。テストは原則一時データを使い、GitHubに非公開データを要求しない。実データ・GPU確認はローカルで行う。資料から参照するローカル実験結果はGitHubには含まれない。

既存の公開デモデータや他アプリは今回変更しない。元からGit管理されたデータは、次のコミットで旧配置からの削除を含める必要がある。`.gitignore`と移動だけで過去コミットのデータは消えない。履歴の書き換え・remoteへのpushは今回行わず、公開前に履歴と秘匿情報を確認する。

## 検証

移動の衝突・プレビュー・元JSON保管・パス限定更新・測定ログ不変を一時フォルダでテストする。移動後にMacAR全テスト、既定地図の推奨選択・画像プレビュー、3DGS/実写の読込と照合、`--help`、VS Codeの参照先、Git除外を確認する。実カメラの起動と描画は未実施ならその旨を報告する。

- 62データ用フォルダ（約18GB）を移動し、運用JSON 73個のパスを更新。原本と移動記録は`data/MacAR/layout-migrations/20261022-142457-793337/`へ保存。
- 実行JSONL 193本は移動前後のSHA-256が全一致。NPZ・画像・XYZ・測定値は書換え対象外。
- 既定地図は同じ`20261002-153042-c033a9/stage_48`。幾何監査合格、XYZ付き観測687,254、付与率77.73%、登録画像`00314.png`のプレビュー成功。
