# 3DGSの透け：表示条件の比較（2026-10-03）

## 目的・範囲

同じPLY・同じカメラから左右に描画し、裏面模様の透けが表示条件で改善するかを確認する。通常の比較画面はカメラ不要・読取専用で、カメラ取得、PnP、XYZ、CT変換、既存DINO参照画像は変更しない。明示的な生成モードでは別フォルダに参照RGBを保存できる。元PLYを編集／上書きしない。

現在のライブ表示はPlayCanvas 2.22.2のunified splat、WebGL CPU非同期ソート、既定の小粒子／寄与カットを使う。CSSによる重畳透過と、GS内部のalpha合成は別物。比較画面のCSS透過は常に100%で、左右の背景・姿勢・解像度を揃える。

## 比較条件

- 左：現行の既定描画。静止させ、sort完了を表示してから比較する。
- 右：既定／小粒子カットなし／高精度カラー格納／WebGPU GPUソート／alpha増強を選ぶ。
- GPUソートは実際のデバイスを表示する。WebGPU非対応でWebGLになった場合はGPU比較成立と扱わない。
- 比較画面の条件切替は表示だけの実験。学習されたopacityを変えるため、透けが減っても真の表面や幾何精度の改善とは限らない。条件を切替えただけで検索用参照へ自動採用することはない。

## 操作・判定

`python3 gs_render_compare.py`（MacAR内）でローカル比較画面を起動する。manifestで指定されたPLYを使う。参照view選択時は既知カメラ行列の回転（真上viewのrollも含む）を再現する。方位／上方角／距離変更、回転では軌道カメラへ切り替え、同じ姿勢を左右へ設定する。

1. 正面・斜め・上方の複数viewで、静止後の透け・輪郭・細い線／マーカーを比較。
2. 回転中と停止後を比較し、ソート遅延と静止時の透けを区別。
3. 両画面の実描画fps、実バックエンド、sort待機を確認。比較画面は2描画なので単独ライブfpsと同一ではない。
4. 改善が見える条件をユーザーへ提示。モデル原因／ビューア原因を見た目だけで断定せず、推奨と制約を結果欄に残す。

本画面はPlayCanvas内の比較で、独立実装との照合や学習時レンダラーとの一致検証ではない。臨床精度の保証にも使わない。

## alpha 1.5参照の置換比較（現行の追加実験）

ユーザーが確認したalpha 1.5を検索参照へ適用し、元参照を残した別フォルダで比較する。128枚のカメラ、roll、解像度、XYZ、幾何QCは固定し、RGBだけを再生成する。再描画alpha 1.0対照も生成し、元画像との差とalpha変更の差を区別する。背景は元参照と同じ白（0.96）。保存は明示的な生成モードだけで有効になり、既存出力は上書きしない。生成中のフォルダは未完成扱いとし、全画像確認後にmanifestを保存する。特徴・検索キャッシュはコピーせず再生成する。

同じ未登録写真、HFOV 72°、写真ALIKED入力1600 px、Top-3、厳格QCで、元参照／再描画1.0／再描画1.5を比較する。登録実写方式（3DGSは粗検索）と3DGS方式（局所照合も仮想RGB）を分ける。参照の初回キャッシュ作成時間は照合時間に含めず別途記録する。ROIが描画に依存する場合、各条件のROIも記録する。

報告値はQC PASS率、採用点数、再投影誤差、処理時間、候補view。未登録写真には独立した真値姿勢がないため、PASS増加を姿勢正解率／CT位置精度の向上と呼ばない。元PLY・元参照・登録実写XYZは変更しない。

### 現行の選択と比較結果

粗検索の改善が立証されていないため、ユーザー指定で両方式の既定を**元参照 `output_3dgs_reference_views_72_upper_negz_v2`**へ戻す。ブラウザ左側の「3DGS参照画像」で「元参照（デフォルト）」／「アルファ1.5（比較）」を選ぶ。アルファ1.5は `output_3dgs_reference_views_upper_rgb_20261003_alpha15`。停止してから変更し、次の開始に反映する。登録実写では粗検索用、3DGS方式では粗検索と局所照合用。フォルダ内のmanifestがない候補は選択不可として表示する。「登録データ・校正ファイル」のファイル選択で他のmanifestも指定でき、その場合は選択欄に「ファイル指定」と表示する。二重の設定を持たず、選択は既存の `views_path` に反映する。

元参照・再描画1.0・1.5、既存の比較結果は保持する。ライブの3DGS表示material、XYZ・PnP/QCの条件は変更しない。直前のalpha 1.5既定への切替は見やすさの希望による研究用選択だったが、以下の結果を受けて既定を戻した。
