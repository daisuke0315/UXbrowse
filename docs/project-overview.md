# プロジェクト概要

## 目的

ViewSync MPRは、CTなどの医用断層画像と患者の外観3Dモデルを同じ物理座標系で扱い、外観モデルを見ながら、その視点に対応する断面画像を直感的に確認できる可視化基盤を目指すプロジェクトです。

現在のリポジトリは、その中核となるブラウザ版MPRビューアのPoCです。診断用医療機器ではなく、患者説明、教育、多職種間の認識共有などに向けた技術検証を目的としています。

## 背景と課題

CTの断面画像は医療者には一般的ですが、患者や非専門家には、身体のどの位置をどの向きから見ている画像なのか理解しにくいことがあります。そのため説明者は、断面位置や向きを言葉や身振りで補足する必要があります。

本プロジェクトでは、断面画像そのものを操作の中心にするのではなく、患者の外観を表す3Dモデルを操作対象とします。外観モデル上の視点とCT断面を連動させることで、「見ている場所」と「内部の断面」の関係を視覚的に結び付けることを狙います。

## 基本コンセプト

本構成の基本的な流れは次のとおりです。

1. CTボリュームをDICOM患者座標（mm）で構築する。
2. 外観3Dモデルを同じ物理座標系へ整合する。
3. 3Dビューアのカメラ位置、視線方向、画面上方向からMPR平面を定義する。
4. MPR画像を再構成し、同じ位置と姿勢で3D空間へ重畳する。
5. 断面より手前にある外観モデルを透過し、内部断面を見やすくする。

座標整合の詳細は[座標系定義](coordinate-system.md)、MPR生成は[MPRアルゴリズム設計](mpr-algorithm.md)、カメラ連動は[Three.js連動MPR](dynamic-mpr.md)を参照してください。

## 外観3Dモデルの位置づけ

研究構想では、写実的な外観表現の候補としてGaussian Splatting（GS）を検討しています。ただし、本質的な要件はGSそのものではなく、外観モデルがCTと同じ物理座標を持ち、その操作から医用断面を一意に導けることです。

現行ビューアが直接読み込める形式はOBJとGLBです。GSの生成工程やGSデータの直接描画は、このリポジトリにはまだ統合されていません。

## 想定利用場面

- 診療時の患者説明
- 医療スタッフ間の認識共有
- 学生、研修医などへの教育
- 術前計画や症例検討を支援する可視化の基礎研究

これらは想定用途であり、現時点で有効性や臨床安全性が確認されたことを意味しません。

## 現行PoCの範囲

現行実装は、DICOM又はMHAボリュームの読込、任意断面MPR、Three.jsカメラ連動、OBJ／GLB表示、MPRプレーン重畳、前景透過をブラウザ内で行います。患者情報管理、PACS連携、診断支援、撮影装置との同期、外観モデル生成は対象外です。

実装済み・未実装・未検証の区別は[研究・開発状況](research-status.md)に記載します。

## 取り扱い上の注意

- 本実装は研究・技術検証用です。診断又は治療判断には使用できません。
- 実患者データを扱う場合は、所属機関の倫理、個人情報保護、情報セキュリティに関する規程へ従う必要があります。
- 特許性、新規性、臨床的有効性に関する記述は、技術的に実装済みであることとは別に評価する必要があります。
