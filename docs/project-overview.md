# プロジェクト概要

## 目的

- CT断面画像と可視光3Dモデルの位置関係を、直感的に観察できるようにします。
- 3Dモデルを操作すると、対応するMPR断面が追従します。
- 患者説明、教育、多職種間の情報共有に向けた基礎検証を目的とします。
- 現在は研究・技術検証用のブラウザPoCであり、医療機器ではありません。

## 基本コンセプト

- DICOMまたはMHAからCTボリュームを構築します。
- CTと同じ物理座標を持つ3Dモデルを読み込みます。
- カメラ位置・視線方向・画面上方向からMPR平面を決定します。
- 同じMPR画像をサブ画面と3D空間内の平面へ表示します。
- 断面より手前のモデルを透過し、内部構造を見やすくします。

## 現在できること

- DICOM／MHA、GLB／OBJのローカル読み込み
- 視線連動、Axial、Coronal、SagittalのMPR表示
- モデルとMPRの重畳、前景透過、CT値しきい値透過
- みかん・バナナの公開デモ表示
- ブラウザ内処理による、外部サーバーへ送信しない観察

## 対象外

- CTと3Dモデルの位置合わせ処理
- 外観モデルの生成やGaussian Splattingの直接表示
- PACS、DICOMweb、患者情報、権限、監査ログの管理
- 診断・治療判断を目的とした機能

## 想定用途と検証状況

- 想定用途：患者説明、教育、症例共有、術前検討の可視化研究
- 実装済み：ブラウザ内での読込、MPR生成、3D重畳、基本操作
- 未検証：臨床的有用性、理解度向上、安全性、実運用性能
- 実患者データを扱う場合は、所属機関の倫理・個人情報・情報セキュリティ規程に従う必要があります。
